# GGX CRM prototype — demo

A clickable prototype of the GoGoX CRM client book and client profile.
**Open it:** https://kanmatilda.github.io/ggx-crm-demo/

- Sign in with any `@gogox.com` e-mail (demo sign-in, no password; nothing leaves your browser).
- Click any user ID to open a client profile.
- All figures are generated placeholder data — no real customers.

This repo holds only the built site. The source is private.
